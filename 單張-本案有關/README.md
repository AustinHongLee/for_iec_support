## 新拆單張命名

- Type 圖：`TYPE-01_D-1.pdf`
- Type 附頁：`TYPE-51A_D-62A-2.pdf`
- M 系列零件圖：`LOWER-COMPONENT-OF-BASE-SUPPORT_M-42A.pdf`
- 索引／說明／清單：依頁尾的 `I-*`、`P-*`、`L-*` 命名

中威原始合併檔內有兩張不同內容但頁尾同為 `P-5` 的頁面，因此保留為
`SELECTION-PRACTICE_P-5_01.pdf` 與 `SELECTION-PRACTICE_P-5_02.pdf`，避免覆寫或遺漏。

原始合併檔均收在各來源的 `_原始合併檔/`；單張直接放在公司或專案目錄，不再多包一層 `單張/`。

20E4588 的 `_INDEX.pdf`、`M1.pdf`、`M42.pdf`、`SPS.pdf` 是索引／零件／專案支撐資料，
不屬於本輪 37 個數字 Type 群組，暫保留原檔名；Type 計算稽核只掃描 `TYPE-*.pdf`。
