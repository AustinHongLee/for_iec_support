## 2. G0 衛生前置(選配,但強烈建議在第一波做掉)

### 模組 G0a:`.gitattributes` 補全 + 一次性 renormalize
- **解決什麼**:現行 `.gitattributes` 只涵蓋 `*.py/json/ini/yml/yaml/ps1/cmd` 與兩個特定 md。`*.md`、`*.sh`、`*.txt`、`*.bas` 未涵蓋 → 從 Linux 沙箱/CI 以外環境看 repo 會出現上百筆 CRLF 幻影 modified(2026-07-12 實測 142 筆),每個新 agent 都會浪費一輪重新診斷。6/15 已發生過一次,6/22 只修了 py 系。
- **動到的檔案(白名單)**:`.gitattributes`;renormalize 影響的檔案(僅行尾)。
- **絕對不要動**:任何檔案的內容邏輯;不得與其他模組混 commit。
- **實作步驟**:
  1. `.gitattributes` 檔首加 `* text=auto`(放最前,讓既有specific規則覆蓋);補 `*.md text`、`*.txt text`、`*.sh text eol=lf`、`*.bas text eol=crlf`(VBA 慣例)、`*.lsp text eol=crlf`。既有 binary 規則保留。
  2. `git add --renormalize .`,單獨 commit「chore: complete line-ending normalization」。
- **DoD**:Windows 端 `git status` 乾淨;隨後在任何 fresh checkout / CI 上 status 也乾淨。
- **驗收指令**:基線四指令全綠;`git diff -w --stat` 為空。
- **停損條件**:renormalize 後 `git diff -w` 非空(代表混入內容變更)→ 還原。
- **規模**:S。
