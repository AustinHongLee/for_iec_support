# Type 105 — 現場配切橫樑支撐

來源為 D-114/D-115；格式 `105-{Member M}-{L/100}{A|B|C|D|E}`。中威與 20E 使用獨立 section 表。

Member M 依 designation L 列備料重，但 D-115 要求現場配切，finished end fit-up 尚未完成。FIG-A 的 Member N 有確切 section/cut，可精算；FIG-C/E 的 Member P 只有 `300 MAX` 外框，不能把 300 當成 finished cut。H294/H390 尚無核定 kg/m，亦不借用相近 H-beam 重量。
