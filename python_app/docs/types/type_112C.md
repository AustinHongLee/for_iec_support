# Type 112C — 斜撐式容器冷保溫支撐

來源：DSP-500-006 C-55 Rev.0。

編碼：`112C-{B mm}-{C mm}`，例如 `112C-200-500`。

目前保存 B、C、預設 45° 安裝角、C180/L130 section 與 stud，並展開 N-28 WOOD-2/3/4 尺寸與孔位。提供 row override `insulation_thickness_mm` 後，可再解析 N-12A CLIP TYPE 3 的 A/plate thickness。

45° 是組立方向，不足以決定 brace 端部 fit-up 與 finished cut；N-28 白橡木密度與 WOOD-2 chamfer 也未完整。目前不以直角三角形外框推算重量。
