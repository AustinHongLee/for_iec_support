# Type 17C — 水平冷保溫導向支撐

來源：C-23/C-24/C-25 Rev.0。編碼：`17C-{A|B}-{CR#}-{LINE}B-G`。

CR2.5~CR40 的 C-23/C-24/C-25 宿主表與 N-15/N-16 組件表分開保存，因為部分 RG/H 是不同 datum，不能互相覆蓋。CR2.5~12 依 N-15 以 `pi*(RG+T/2)+2H` 算 U-band 中性線展開；CR14~40 依 N-16 以 `pi*(RG+T/2)+2*(H+10)` 算展開，並加入兩支 Member M cut/steel weight。幾何 flat pattern 已可產生，但圖面只寫 carbon steel、未給 grade。CR14~25 由宿主圖保留 2 支、CR26~40 保留 4 支 machine bolt reference；bolt grade/nuts 與 Member-M joint/weld recipe 尚未完整。
