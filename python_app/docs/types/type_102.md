# Type 102 — D-111 E-Plate Interface

中威與 22A D-111。D-80 pipe shoe 與 existing member 均標示 not furnished；本 Type 只處理 E-plate interface。

來源表已記錄 E plate 厚度與 W weld。6" 是來源差異點：中威仍為 E=9/W=6，22A 已切換為 E=12/W=10。FIG A/B 的 40/75、50、60、G=50、3 mm gap 與 80/100 bearing 控制尺寸均保留。

完整 E-plate 平面輪廓與分片邊界未唯一標出，因此目前不以 100×80 外框估重，輸出零重量 interface-set reference。
