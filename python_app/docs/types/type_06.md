## 系統本質

雙管共用托板，型鋼立柱，底部為 M-37 Type-F Lug Plate 與 K bolt

雙管平行坐在橫向托板上的立柱支撐。Member C 可為 L50／L65／L75／C150，包含垂直與水平段。H≤1500 mm、L≤1000 mm，兩者均需現場切配。底部 M-37 Type-F Lug Plate 與 K bolt 均列入 BOM；無 U-bolt、無 M-42。

## 核心運算邏輯

```text
型鋼兩支（垂直 H + 水平 L）+ M-37 Type-F Lug Plate + K bolt。

垂直型鋼長度 = H×100
水平型鋼長度 = L×100
角鋼分支：M-37 兩孔板 + 2 支 K bolt
C150 分支：M-37 四孔板 + 4 支 K bolt
```

---

## 設計重點

- 無 `M-42` 下部構件；底部板依 M-37 表列幾何計算梯形淨面積並扣除螺栓孔。
- 圖面 note 2 標示 `H` 與 `L` 需現場切配；可用實際下料長覆寫，否則構件維持加工阻擋。
- 原圖範例 `06-L50-0510-0401` 的 A+B=500 mm，但 L=1000 mm。系統保留原編碼並明示組立阻擋，不擅自改成相等。
- M-37 的 LGP-F-8 來源尺寸為 `C200×90×8`，已修正舊資料的 `C200×80×7.5`。
