# Type 20C — 冷容器至裸管支撐

來源：C-29/C-30/C-31 Rev.0。編碼：`20C-{LINE}B-{C mm}`。

依 4 吋以下、6/8/10、12~24 吋保存 section、clip/strap/U-bolt/wood-block chain 與 B formula。6/8/10 吋會接入 N-8A 的 R/A/B/T、100 mm width、2-Ø22 holes 與 3/4×50 bolts。

C 是 assembly reach；N-8A 沒有 flat development/bend allowance，N-12/N-28/M-26 亦未完整，因此不把 formed A 或 C 當 finished cut。
