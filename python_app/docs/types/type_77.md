# Type 77 — Large-Pipe Saddle

| 項目 | 內容 |
|---|---|
| 圖面 | D-92 |
| 編號 | `77-{line_size}B-(A|S)` |
| 範圍 | 26"~40" 表列尺寸 |
| 狀態 | 組立尺寸已轉錄；cutting recipe 未完成，重量阻擋 |

D-92 的 saddle 由多片斜板、120°／20°／30° 接觸輪廓與 reinforcing pad 組成。A/B/C/T/H 是組立控制尺寸，不是單一矩形板。

舊版 `(C×H + A×B)×T` bounding weight 已停用。系統保留 D-92 尺寸、材質符號、weep hole 與焊接資料，但在各 piece 的片數、淨輪廓及展開完成前，只輸出零重量 `SADDLE ASSEMBLY` reference。

`(A)`／`(S)` 是 D-80A 材質符號，不是 anchor type。
