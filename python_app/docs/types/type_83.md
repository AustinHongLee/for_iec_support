# Type 83 — Axial-Stop Pipe Shoe

| 項目 | 內容 |
|---|---|
| 圖面 | D-101 / D-102；20E 另有 D-101A |
| 來源 | 中威、22A_5123A、20E4588 |
| 結構 | 同來源 D-80/D-96 shoe + axial-stop assembly |

基礎 shoe 直接復用所選專案來源的 Type 80 規則，不會由編號猜來源。小管 axial stop 依來源使用 9t plate、L40 或 L50；大管使用 No.1~No.4 多片組立。

axial-stop 沿管 cut length、完整片數，以及 fireproofing beam 對應尺寸未由 designation 唯一決定，因此目前保留零重量 reference；可算的 D-80 子構件仍保留其 BOM 與加工資料。
