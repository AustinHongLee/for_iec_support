# Type 60 — D-71 Large-Bore Side Support

> 2026-07-30 依中威 D-71 全重製。只有中威來源可用。

## 輸入

`60-{LINE SIZE}B-{A|B}`

- FIG-A：insulated pipe，引用 D-80／D-80B shoe。
- FIG-B：bare pipe，翼板包含 45° 配置與 120° 貼管切口。

## 組件拆分

原圖每側有：

- B×D base plate 1 片
- wing plate 2 片

因此整組 BOM 為 base plate 2 片、wing plate 4 片，材質明確為 `A283 Gr.C`。

## 加工圖狀態

### FIG-A

- Base：B×D×T，2 片。
- Wing：依 A／B／C／P25 淨形計重，4 片。
- 板件 BOM 可用；D-80／D-80B shoe 明示 `NOT FURNISHED`。
- 與 shoe 的最終貼合定位仍需專案 shoe 尺寸，因此整組加工圖尚未 complete。

### FIG-B

- Base：B×D×T，2 片，可直接下料。
- Wing：4 片，但 D-71 沒有足以展開 45°／120° 貼管切口的座標與半徑基準。
- Wing 以零重量 reference 輸出，BOM／加工圖 blocked；不再用 A×B 外接矩形假估重量。
