# Type 101 — Small-Bore Connection Rib

中威與 20E D-110 均使用 6t×50 flat bar、60° 與 190 mm vertical envelope。中威為三片 rib、120° 等分；20E 為單片並有優先／次選安裝位置規則。

190 mm 是組立垂直包絡，不是 finished rib length。rib 兩端需貼合 main/branch pipe 曲面；缺兩管實際 OD、交角與 cope contour 時，禁止以 `190/sin60` 估長，故目前輸出零重量 rib-set reference。

20E 圖面的 designation 與 note 對 `(A)/(R)` 定義有衝突，系統保留警告等待工程確認。
