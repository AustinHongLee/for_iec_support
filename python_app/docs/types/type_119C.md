# Type 119C — 管嘴冷保溫支撐組立

來源：DSP-500-006 C-67 Rev.0。

編碼：`119C-{CR#}-{LINE}B`，例如 `119C-CR12-8B`。

系統只接受 C-67 明列 nominal sizes：1/2~12 吋選 L75×75×9 Member Q，14~24 吋選 L100×100×10，並保存 450 foam/vapor、400 jacket、300 cradle 與側邊 foam 最小 10 的 envelope。

N-1/N-2/N-3/N-5/N-20~N-23 現可解析表列管徑的 R/T1/F/H、PU layers、密度與容許載重，300 cradle 也可解 N-3 軸向長度。C-67 範圍內但 N-20~N-23 未逐列列出的 nominal size 保留 unresolved blocker；Member Q 無成形展開，仍輸出零重量 assembly reference。
