# Type 82 / 82A — Guide / Fixed Pipe Support

| 項目 | Type 82 | Type 82A |
|---|---|---|
| 圖面 | D-99 / D-100 | D-100A-1 / D-100A-2 |
| 功能 | guide，管側保留 3 mm | fixed，Member M 焊於管側 |
| 來源 | 中威 E25-24 | 中威 E25-24 |

Member M angle 的規格、cut length、數量 2 與 6 mm weld 已按原圖建檔，可作加工資料。兩型共用尺寸表，但不共用間隙與來源圖。

Member C／大管 saddle 可能由切割母型鋼或多片板組成。A/B/D/E 是組立控制尺寸，不是單片 blank；在各 piece 淨輪廓、方向與片數完成前維持零重量 reference。
