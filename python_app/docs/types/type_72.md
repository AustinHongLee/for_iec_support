# Type 72 — Strap Support

| 項目 | 內容 |
|---|---|
| 圖面 | D-87 / M-54 FIG.2 / M-45 |
| 編號 | `72-{line_size}B` |
| 範圍 | 3/4"~4" |
| 狀態 | 尺寸 lookup 完成；重量與加工展開阻擋 |

M-54 的 A/B/C/T/H/R/D 表與兩個 Ø11 孔已轉錄，但 `B` 是成形後外側跨距，不是已證實的平板展開長。沒有 bend allowance／展開基準時，不得用舊版 `B×C×T` 算 strap。

D-87 指定兩組 EB-3/8 expansion bolts；M-45 有尺寸與能力資料，但沒有材料與來源單重。系統因此輸出兩個零重量 reference，並以 fabrication blockers 明確標示缺口。
