# Type 23 - 頂掛式懸臂支撐

- 圖面：D-25
- 編碼：`23-{M}-{HH}{A/B}` 或 Fig.C 的 `23-{M}-{HH}C-{LL}`
- BOM：垂直 member H 一支、水平 member L 一支
- 來源差異：中威與兩份中鼎的 member 種類、L/H 上限不同；未表列 member 仍硬停止，L/H 則採有限外插分級。
- 加工狀態：BOM 可算；下角接頭端切、該處焊腳與管線止滑/固定方式未由 D-25 定義，仍不可直接出完整加工圖。

管線直接坐於水平 member，圖上沒有 D-68 U-bolt。上端保留 6 mm 全周現場焊及管中心距自由端 100 mm。

L/H 小幅超界為一般警示，較大但仍在護欄內者為高風險；超過圖示上限 2 倍或超額逾 2000 mm 仍停止。
