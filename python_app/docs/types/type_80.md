# Type 80 — Beam-Mounted Pipe Shoe

| 項目 | 內容 |
|---|---|
| 圖面 | D-95 / D-96 / D-80 family |
| 編號 | `80-{size}B[(P)]-{A|B|C}(material)-{HOPS}-{LOPS}` |
| 來源 | 中威、22A_5123A、20E4588 已分 profile |
| 狀態 | 小管 H-section 分支可算；fabricated member 與 D-96 大管組立阻擋 |

## D-95：24" 以下

D-95 明確要求 upper shoe detail 參照 D-80，因此系統復用同來源的 Type 66 recipe，再加入 beam-interface member C。各來源表不同，例如 6" 的 A 在中威為 100、22A 為 200；20E 10" 的 B 為 100，而中威為 200。

- H-section branch：編號有明確 LOPS 時可列備料重量，但 NOTE 2 的 field-fit 仍是加工圖 blocker。
- 16"~24" fabricated-from-12t branch：完整拆片／輪廓未形成前為零重量 reference。
- 22A/20E 的 fireproofing 選配沒有尺寸輸入時不會自動加入。

## D-96：26" 以上

中威與 22A 表列 26/28/30/32/36/40/42"；20E 只表列 26/28"。D-96 主 saddle 引用 D-80B，多件側板、弧板與 stop parts 不能用矩形外包估重。系統保留尺寸與來源差異，但在各 piece 的淨輪廓、片數及 cut length 完成前輸出兩個零重量 assembly references。
