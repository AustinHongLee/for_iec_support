# Type 28 - 門型支撐

- 圖面：D-31
- 編碼：`28-{M}-{LL}{HH}{M42}`
- BOM：左腿 H + 上梁 L + 右腿 H，另有左右各一組 M-42；相同 M-42
  幾何在材料明細中合併為單列、數量 ×2，左右安裝位置保存在結構化參數
- M-42 主體圖列舉：中威 L/P；兩份中鼎 L/T
- 加工輸入：`line_orientation` 與 `supported_line_layout`

水平管或垂直管配置不能由角鋼/槽鋼種類自動猜，因為 designation 沒有編入這個分支。垂直管配置使用 D-68 U-bolt，且圖面標示不供應。門架角部端切/貼合也需在加工圖階段展開。

若 designation 的 M-42 不在 D-31 列舉內，但該來源自己的 M-42 標準確有定義，
系統會高風險暫算並卡正式放行；來源標準也沒有時仍停止。L/H 同樣採有限外插分級，
不允許超過上限 2 倍或超額逾 2000 mm。

M-42 fastener 若來源只有名義直徑而沒有長度，會保留在
`excluded_bom_components` 與 blocker，不顯示成 0 kg 採購列。
