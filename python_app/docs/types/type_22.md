# Type 22 — D-24 落地懸臂 U-bolt 支撐

三來源的外形相近，但編碼、member 表與允許的 M-42 型式不同。

| 來源 | designation | member / envelope | D-24 允許 M-42 |
|------|-------------|-------------------|----------------|
| 中威 | `22-M-HH(Fig)M42[-LL]` | L50/1000、L65/1000、L75/1500、C100/2000；未列 L(MAX) | L、P |
| 22A | `22-M-HHFig-M42[-LL]` | L50/1000/500、L75/1500/800（H/L max） | L、T |
| 20E4588 | `22-M-HHFig-M42[-LL]` | L50/1000/500、L75/1500/800（H/L max） | L、P、T |

Fig A/B 的 L 固定 300/500 mm；Fig C 的末段為 `L/100`。未表列 member、
來源編碼錯誤，以及同來源 M-42 標準也未定義的型式仍會停止。若型式只是不在
D-24 的列舉內、但同來源 M-42 標準確有定義，系統會列為高風險暫算，不會冒充
正式可用組合。

H/L 超出圖示 envelope 時採有限外插：小幅差異為一般警示，較大差異為高風險；
實際值超過上限 2 倍或超額逾 2000 mm 時仍停止。所有外插都禁止直接視為可出加工圖。

BOM 包含垂直 H 段、水平 L 段與來源對應的 M-42 下部構件。H 雖要求現場切合，
但已編入 designation，作為實際切長。D-68 U-bolt 不供應。

已保存 H/L 切長、自由端至管中心 100 mm、M-42 plate/孔與扣件資料。
加工圖仍缺上角接頭端切／焊腳以及 D-68 孔位。中威 C100 雖在 D-24 member
表內，但既有 M-43 沒有 C100 精確 row；目前只可顯示 C125 row 的估算，
因此該分支 `bom_ready=false`，不可當正式下料。
