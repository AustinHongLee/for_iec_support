# Type 121C — 大口徑冷保溫導向支撐

來源：DSP-500-006 C-69/C-70 Rev.0。

編碼：`121C-{CRADLE LENGTH CODE}-{CR32~CR46}-{LINE>=30}B-G`，例如 `121C-B-CR42-30B-G`。

CR32~CR46 的 W、H、h1、h2 與 H125×125×6.5×9 Member Q 長度已逐列轉錄。C-70 圖示左右各一支 Q，所以系統計算兩支型鋼備料重。

N-1/N-2/N-3/N-5/N-24~N-26 現會交叉驗證 CR/pipe 並解析 insulation/F/H/R/T1/A/B/320 kg/m³/容許載重。圖面仍未指定 Q 的鋼材牌號；6t X/Y/stiffener plates 也缺完整淨輪廓，因此型鋼可備料，但完整 BOM 與加工圖仍受阻。
