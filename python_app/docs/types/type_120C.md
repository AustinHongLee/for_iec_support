# Type 120C — 冷保溫吊架組立

來源：DSP-500-006 C-68 Rev.0。

編碼：`120C-{CRADLE LENGTH CODE}-{CR#}-{LINE}B-{ROD SIZE}-{H mm}-{A|B}`，例如 `120C-A-CR4-2B-1/2-1200-A`。

FIG-A 使用 M-22 machine threaded rod 與 M-25 weldless eye nut；FIG-B 使用 M-23 welded eye rod。兩支均在 `H > 2000` 時需要 M-21 turnbuckle。

H 是完整吊架高度，不是 rod finished cut；CR/pipe 會接入 cold-core lookup。N-17/N-18/C-24 與 M-series hardware 未完整核定前，系統保存 component chain 但不以 H 推算重量。
