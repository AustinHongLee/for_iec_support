# Type 25 - 兩件式懸臂支撐

- 圖面：D-27
- 編碼：`25-{M}-{LL}{HH}{A/B/C}[-{L1}{L2}]`
- BOM：H 向 member 一支 + L 向 member 一支
- L1/L2：若有第四段但總和不等於 L，仍按 L/H 顯示暫估 BOM，但列高風險且不得正式放行
- Fig.C：依 M-34 精確表輸出 Lug Plate Type-C 一片；孔數與 K Bolt 數依版型為 4 或 6

三來源的 member/envelope 分開。中鼎 Fig.A 的 fire-protection detail 仍需專案選擇；Fig.B 的 D-68/D-70 均標示不供應。加工圖仍需補角部接頭端切與焊接展開。

L/H 超界採有限分級，超過圖示上限 2 倍或超額逾 2000 mm 仍停止，避免無限制外插。
