# Type 49 — D-60 Riser Clamp 支撐

> 2026-07-30 依中威 D-60 Rev.1 與 M-11／M-12／M-41 Rev.1 重製。只有中威來源可用。

## 輸入

原圖正式格式：

`49-{LINE SIZE}B-{FIG A/B}{MATERIAL SYMBOL}`

例如 `49-3/4B-A(A)`。

FIG 段不得省略；`49-10B` 這種兩段字串會明確報錯，不再把管徑尾碼 `B`
誤判成 FIG-B。混合分數可寫成 `49-1-1/2B-A`。

D-60 的 FIG-A 與 FIG-B 都適用 3/4"～20"，但 M-11／M-12 只允許原表
實際列出的 NPS，不做區間內插。

## 分支

| Figure | 引用構件 |
|---|---|
| A，3/4"～2-1/2" | M-11 Riser Clamp Type-A + fastener reference |
| A，3"～20" | M-11 + fastener reference + M-41 Lug Plate Type-P |
| B，3/4"～20" | M-12 + fastener reference；3" 以上另列 FIG-B lug 歧義 |

D-60 Table A 的空白／`(A)`／`(B)` 表示 plate 的 Carbon／Alloy／Stainless
材料類別。M-11／M-12 原圖本身固定寫 Carbon Steel，因此 clamp 不會跟著
plate 材料符號變成合金鋼或不鏽鋼。M-41 內部 designation 的 stainless
suffix 是 `S`，系統會由 D-60 的 `(B)` 正確轉換。

## 已計算範圍

- M-11／M-12：逐列保存最大建議荷重、A/L、扁鋼厚度與寬度、螺栓規格。
  依標準管外徑與扁鋼中性層計算兩片半圓彎製扁鋼毛重。
- M-12 以逐尺寸表列 L 反推直段總長並計算已知扁鋼毛重。草圖固定
  150／50 與表列 L 最多相差 34 mm，故只保留為來源註記，不當成已釋出
  的左右下料尺寸。
- M-11 只有總長 A；左右對稱直段是由 A、管外徑與兩倍板厚反算，因此只
  用於毛重，不能當成已釋出的加工尺寸。
- M-41：依 A/B/C/D 梯形輪廓扣除三角缺角，以 T 與表列數量計算 plate
  blank 重量。

M-11 與 M-12 不可視為同一表。例如 10"：

| Component | A/L | Stock | Bolt |
|---|---:|---|---|
| M-11 | 514 | 9×51 | 5/8"×70 |
| M-12 | 527 | 10×51 | 5/8"×60 |

## 加工圖狀態

目前總重是「可證實鋼材範圍」，不是完整成品重量：

- M-11／M-12 未標螺栓孔徑、孔中心距、端部圓角、材料牌號／鍍層與
  螺栓螺帽成品重量；兩個螺栓位置已另列零重量採購 reference。
- FIG-B 3" 以上畫有疑似 lug 的小矩形，但只有 FIG-A 有 M-41 引線，且
  D-60 引用的 NOTE 2 遺失；未經原設計確認前不自行增刪 M-41。
- M-41 的平面梯形 blank 已完整，但管面端只給 S、`T/2-S` 與 6 mm
  焊接註記；坡口長度／角度及三維貼合輪廓不足。
- 螺栓螺帽、孔洞扣重、M-41 管面端加工扣重與焊材重量均未硬估。

因此 Type 49 會回傳正的已知鋼材重量與完整來源參數，但
`bom_ready=false`、`fabrication_ready=false`，直到缺少的加工與採購資料
補齊。
