# Type 22C — 冷容器至冷管支撐

來源：C-35/C-36/C-37/C-38 Rev.0。編碼：`22C-{A|B}-{CR#}-{LINE}B-{C mm}`。

依 2 吋以下、3 與 4 吋、6/8/10、12~24 吋四支保存 section/restraint/B formula，並以 N-20~N-23 驗證 CR/pipe、解析 insulation/F/H/load。

2 吋以下接 N-7A，可計 U-bolt rod 中心線展開與 rod-only 重量；3/4 吋接 N-8 的 R/A/B/T/holes。N-7A nuts/thread 與 N-8 flat development 仍阻擋完整加工，C/C-21 geometry 也不當 finished cuts。
