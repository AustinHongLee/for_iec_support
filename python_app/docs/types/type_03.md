## 系統本質

≤2" 小管徑用，角鐵 L75×75×9 立柱 + U-bolt 固定 + M-42 底板

適用於 2" 及以下小管徑管線的彎頭支撐。D-3 只指定 U-bolt 的位置與數量，未提供規格、材質與單重；系統不再套用舊的 SUS304／1 kg 假設。

H 上限採有限外插分級。D-3 未列但同來源 M-42 標準已定義的底板可高風險
暫算；未表列管徑、缺來源或來源 M-42 也未定義者仍停止。

## 核心運算邏輯

```text
角鐵 L75×75×9 兩支 + U-bolt 1 SET（單重待定）+ M-42 底板

垂直角鐵估算長度 = H×100 + 彎頭中心半徑 + supported line OD/2 + 20
預設彎頭中心半徑 = 1.5×NPS×25.4（D-3 未明定，屬可覆寫假設）
水平角鐵長度 = 130mm
```

Example:

```text
03-1B-05L
垂直角鐵 = 5×100 + 1×25.4×1.5 + 20 + 33.4/2 = 574.8mm
```

## 設計重點

- 與 `M-42` 下部構件有關，最終組成會受到末段字母或允許型別限制。
- 圖面立面中 `H` 是到 grade/plate 的現場尺寸，不是垂直角鐵下料總長；下料需加上 LR elbow center、20mm offset、以及 supported line 半徑。
- U-bolt 保留為 BOM 身分與數量，但規格、材質、單重均為加工／採購阻擋；輸入明確覆寫後才可解除。
- `H` 為現場尺寸；彎頭中心半徑與垂直下料長可用專案實值覆寫。未覆寫前不可把估算值直接當成加工圖定尺。
