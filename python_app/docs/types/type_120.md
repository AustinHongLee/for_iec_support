# Type 120 — 非鐵管錨定支撐

來源為中威 D-133/D-134 與 M-57/M-58/M-59；格式 `120-{line}B-{actual pipe OD mm}`。

guide hardware 沿用同圖證實的 Type 119 分流。D-133 另要求 M-57 lower half `CUT 3MM FOR WELD`，大管 M-59 也標記 `CUT TO SUIT`，因此兩者標準件展開只保留尺寸參考、不作 Type 120 finished weight。D-134 的 `E=OD/2+2H`、`F=1.5H` 與 collar `T+3` 已保存；anchor collar/pour shoulder 的 taper、分片、W tolerance 與 field-pour scope 未完整前不以外框估重。
