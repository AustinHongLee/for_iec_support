## 系統本質

彎頭滑動支撐，含dummy pipe(B) + 支撐柱(C) + 底板(E) + 滑動板(F) + M42(僅J)

有滑動面的彎頭支撐，允許管線熱位移。Pipe B(dummy)=L+200，Pipe C(支撐柱)=H-200-Plate F厚-M42板厚。H 現場調整且來源範圍為 `1500 < H < 3500 mm`。下限仍硬停止；上限採有限外插分級。D-7主體圖列M-42 J，其他型式只有在同來源M-42標準已定義時才可高風險暫算。

Warning: H值長是欲保留現場裁切預量

## 設計重點

- 與 `M-42` 下部構件有關，最終組成會受到末段字母或允許型別限制。
- 圖面標示共同 offset `200`；同一值用於 Pipe B 加長與 Pipe C 扣除。
- 圖面 note 2 標示 `H` 需現場調整；端點 1500 與 3500 均不接受。
- Pipe B 與長半徑彎頭的貼合端輪廓，以及 Ø6 weep hole 中心離底板尺寸，原圖未完整尺寸化；未補工程尺寸前不可直接出完整加工圖。
- D-7 未指定舊程式所列的 SUS304／4 kg U-bolt，因此已移除該假 BOM。
- 此型式重點在滑動或限位功能，應優先比對圖面上的止擋、滑板與間隙設定。
