# Type 116C — 三型式冷保溫介面支撐

來源：DSP-500-006 C-62/C-63 Rev.0。

編碼：`116C-{CRADLE LENGTH CODE}-{CR#}-{LINE}B-{C mm}{A|B|C}`，例如 `116C-A-CR8-1B-500A`。

尾碼必須明選：

- FIG-A：vessel clip、N-13/N-7、C-14 steel shoe 與 C-21/C-26/C-27 cold support。
- FIG-B：N-12 Clip Type 1、N-28 Wood Block 1、C-21、4 支
  3/4"×120 A193 Gr.B8 stud 與 8 顆 A194 Gr.8A nuts；保留
  N-12A NOTE 2 的 A 尺寸來源鏈。
- FIG-C：existing surface 與 C-21。

CR/pipe 會接入 cold-core selection/layer/material lookup。FIG-A 另外依 CR 接 N-7，解析 rod/B/C/D/E、中心線展開與 rod-only 重量；finished nuts 仍為零重量採購 reference。FIG-A 同時接 N-13 Clip Type 5 的 10t 雙板、170x160 立面、2-DIA22 孔與 6 mm weld。

FIG-B 依 C-63 使用 320 kg/m³ polyurethane 例外，並保存 4-DIA22、
180/40/100 的接合幾何；stud/nut 因無成品單重仍是零重量採購 reference。
N-13 平面仍需設備半徑 Q/R、theta、B 與 insulation t，且由 vessel
vendor furnish/weld。各 FIG 的 clip/wood/shoe/member finished cuts 不互相
套用；FIG-B/C 仍是組立未完成狀態，FIG-A 也不因 rod 可算就宣稱整組完成。
