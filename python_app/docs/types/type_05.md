## 系統本質

≤2" 角鋼立柱支撐，U-bolt固定(不含供貨)，M42僅允許 D/L/P/R

適用於2"及以下管線的立柱式上托支撐。角鋼Member M(L50/L65/L75)作垂直柱+水平托板(130mm)，U-bolt束制管線(不含供貨,見D-68)。H現場裁切,圖示最大1500mm。D-5主體圖列M-42 D/L/P/R；其他型式只有在同來源M-42標準已定義時才可高風險暫算。

H 上限採有限外插分級；未表列 member、缺來源或超出外插護欄仍停止。

## 設計重點

- 與 `M-42` 下部構件有關，最終組成會受到末段字母或允許型別限制。
- 圖面 View A-A 標示 supported line 中心/托件位置有 15mm offset；垂直 member 下料不是完整 H，而是 `H×100 - 15`。
- 圖面若標示 `U-bolt NOT FURNISHED`，現行 calculator 不會把該夾具列入 BOM。
- `H` 為現場尺寸；即使公式可得名義下料長，未輸入現場實測值前仍不可直接視為加工圖定尺。
