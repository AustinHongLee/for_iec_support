# 益高(E-KO)支撐圖面編號文法普查

製表 2026-07-21。SUPPORT-單張 71 張。供 Phase 2 建置分群。


## 文法家族

| 家族 | 典型文法 | 策略 |
|---|---|---|
| FS | `場撐 Field Support` | 固定字母前綴＋多維尺寸(序號/管徑/L/H/H1/型式)。子形狀多，需 FS 專屬 parser + 每張各自 config。FS12 樣板已可延伸。 |
| PU | `托撐 Pick-Up` | 固定字母(B/E/W)＋管徑＋長度(±H)。PU1 例外(荷重型A/B)、PU21/23 無管徑段。近 FS 樣板。 |
| SS | `結構撐 Structure Support` | 固定/方向字母＋序號＋H/L。主流 {B/W}-□H-□L(5張)；變體含雙高度SS13、雙字母SS21/22、選型SS34、公式SS33。 |
| 單段徑 | `單段管徑 CODE-□"` | 僅管徑一段查表。最單純，可共用一支極簡 parser。 |
| 徑+H | `管徑＋高度 CODE-□"-□H` | 管徑＋高度兩段。 |
| 保冷 | `保冷系列 …-C□` | 含保冷厚度段(C前綴)，多與 cradle/主管相依。 |
| 附撐 | `附撐 Dummy CODE-□"-□L` | 彎頭延伸附撐；材質常同主管。 |
| Trunnion | `凸緣管 ST-□"-□L-T#` | trunnion 支數碼 T1/T2。 |
| 水泥墩/子件/五金 | `子件(CM1/UB1/EB2/DFS4/CL5/S1…)` | 被主支撐引用的共用件；需先建，供跨圖 BOM 串接。 |
| 索引/圖例 | `I-*/L-*` | 非支撐；I-1/I-2 是稱呼代號一覽(文法DB來源)，L-* 是外觀縮圖。 |

## 固定/型式字母

- `A` = 基礎螺栓固定(L型基礎螺栓 A307-B，A/E常含水泥墩)
- `B` = 螺栓連帽固定(A307-B 鍍鋅)
- `E` = 擴展螺栓固定(EB2-)
- `W` = 焊接固定(免螺栓/免鑽孔/免水泥墩)
- `N` = 不固定
- `S/V (SS,SS21/22,SS1)` = 方向/朝向(S平行水平 / V垂直)
- `H/V (FS15)` = 支撐型式(H水平頂承 / V垂直靠夾)
- `A/G (SUB1)` = 緊配 TIGHT / 鬆配 LOOSE
- `A/B (PU1)` = 單邊 / 雙邊 荷重型
- `S/N (DS1)` = 須熱處理或不銹鋼 / 無須熱處理
- `T1/T2 (ST)` = 單 trunnion / 雙 trunnion
- `A~E (CM1)` = 水泥墩型式 A/B/C/D/E

## 異常/待補

- FS19 標題欄公司為『尚得富工程 SATURN ENGINEERING』(高雄)，非 E-KO——混入他家標準圖，建模時標記。
- FS32 全數缺圖，但 FS31(1 OF 2)、FS33 皆引用其 BLOCK-N/BLOCK-1；且 L-2 縮圖出現 FS32。→ 需向使用者索取。
- CS1、VG5 皆為 1 OF 2，稱呼代號與部分件號表在缺失的第 2 頁。→ 需索取。
- L-3 縮圖出現 PU13，但索引/詳圖為 PU12——代號不一致，須人工確認。
- 部分圖(FS22/31/33、SS15/21/22)標題欄或線條偏淡，內容仍可辨識。

## Phase 2 建議順序

- **1. 子件先行**：UB1、CM1(A~E)、EB2、DFS4、CL5、S1 — 被主支撐大量引用；先建好才能串主支撐 BOM。多為單段/查表，快。
- **2. FS 場撐群(18)**：FS1~FS33、DFS4 — 沿用 FS12 樣板；建 FS 專屬 parser 處理固定字母＋序號/管徑/型式/L/H/H1 變體。量最大、樣板重用度最高。
- **3. SS 結構撐群(17)**：SS1~SS37 — 主流 {B/W}-□H-□L 一支 parser 吃 5~7 張；另處理 SS13/21/22/33/34 變體。
- **4. PU 托撐群(8)**：PU1~PU23 — 近 FS；PU1(荷重型)、PU21/23(無管徑) 特例。
- **5. 單段徑導架/錨定/管蹄**：A3,G1,G2,S1,VA1,VA2,VG1,VG2,ST3,CL5,UB1 — 極簡 parser CODE-□" / -□H；量多但快。
- **6. 保冷系列**：CS2,SUB1,SUB2,(CS1*,VG5*) — 含保冷厚度；CS1/VG5 待補第2頁。
- **7. 其餘**：ST,DS1,DS3,CM1 — trunnion/附撐/水泥墩。
