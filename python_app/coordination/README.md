# Coordination Archive

Files in this folder are collaboration logs, handoffs, review notes, and historical snapshots from previous AI/human sessions.

They are useful for understanding why a change happened, but they are not current calculation truth.

Use them only after checking:

1. Current user instruction.
2. Original drawing/PDF.
3. `python_app/core/`, `python_app/data/`, `python_app/configs/`.
4. `python_app/tests/` and `python_app/validate_tables.py`.

If a coordination note conflicts with implementation or tests, trust implementation/tests and record the conflict before changing behavior.
